
# Secure CI/CD Pipeline with GitHub Actions and AWS

## Project Objective
Build a secure automated CI/CD pipeline using GitHub Actions and AWS.

## Technologies
- Git
- GitHub
- GitHub Actions
- Gitleaks
- Checkov
- AWS IAM
- AWS OIDC
- Amazon S3

## Project Features
- Automated application validation
- Secret scanning
- Infrastructure security scanning
- Secure AWS authentication
- Automated deployment to Amazon S3

## Application
A static website demonstrating automated deployment through a secure DevSecOps pipeline.
